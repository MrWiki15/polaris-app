┌─────────────────────────────────────────────────────────────────┐
│ 🛡️ QUÉ SE CREA Y POR QUÉ                                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  TABLA: backups                                                │
│  ├─ Almacena los datos sincronizados de los usuarios           │
│  ├─ Estructura:                                                │
│  │  ├─ id (UUID) - Identificador único del respaldo           │
│  │  ├─ user_id (UUID) - ID del usuario (auth.users)           │
│  │  ├─ data (TEXT) - JSON stringified de los datos             │
│  │  ├─ created_at (TIMESTAMP) - Cuando se creó                │
│  │  └─ updated_at (TIMESTAMP) - Última actualización           │
│  │                                                             │
│  │  (Auto-actualizado por trigger)                            │
│  └─ Constraint UNIQUE(user_id) - Solo 1 respaldo/usuario      │
│                                                                 │
│  ÍNDICES (2):                                                  │
│  ├─ idx_backups_user_id                                        │
│  │  └─ Búsquedas rápidas por usuario                          │
│  └─ idx_backups_updated_at DESC                                │
│     └─ Ordenamiento rápido por fecha                           │
│                                                                 │
│  RLS POLICIES (4):                                             │
│  ├─ SELECT  → Usuario ve solo SUS respaldos                   │
│  ├─ INSERT  → Usuario inserta con SU ID                        │
│  ├─ UPDATE  → Usuario actualiza SOLO sus respaldos            │
│  └─ DELETE  → Usuario elimina SOLO sus respaldos              │
│                                                                 │
│  FUNCIÓN: update_backup_timestamp()                            │
│  └─ Auto-actualiza updated_at en cada cambio                  │
│                                                                 │
│  TRIGGER: update_backups_timestamp                             │
│  └─ Ejecuta la función automáticamente                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 🔐 SEGURIDAD (ROW LEVEL SECURITY)                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ¿Qué es RLS?                                                  │
│  ────────────────────────────────────────────────────────────  │
│  Row Level Security es una feature de PostgreSQL que           │
│  asegura que cada usuario solo acceda a sus datos.             │
│                                                                 │
│  ¿Cómo funciona?                                               │
│  ────────────────────────────────────────────────────────────  │
│  1. El usuario se autentica con Supabase                       │
│  2. Supabase obtiene su JWT token                              │
│  3. Las políticas validan el JWT                               │
│  4. Solo se devuelven filas donde user_id = auth.uid()         │
│                                                                 │
│  Ejemplo:                                                       │
│  ────────────────────────────────────────────────────────────  │
│  Usuario A intenta: SELECT * FROM backups;                     │
│  RLS filtra automáticamente y devuelve SOLO sus datos          │
│                                                                 │
│  Usuario B intenta: SELECT * FROM backups WHERE user_id='A';   │
│  RLS rechaza la consulta (A ≠ B)                               │
│                                                                 │
│  ✅ RESULTADO: Máxima seguridad sin código adicional            │
│                                                                 │
